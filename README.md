# Dailies

One second a day — a free, private rebuild of 1 Second Everyday with every Pro feature. Phone-first web app (add to Home Screen). Everything is stored on the device in IndexedDB; no account, no server.

Static site, no build step: `index.html`, `app.js`, `db.js`, `media.js`, `render.js`, `styles.css`, `sw.js`.
